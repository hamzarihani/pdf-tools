# Contributing to pdf-tools

First off, thanks for taking the time to contribute! 🎉

## Development Workflow

This repository is an npm workspace monorepo. 

1. **Fork & Clone** the repository.
2. **Install dependencies** from the root:
   ```bash
   npm install
   ```
3. **Build packages** before running apps if you made changes:
   ```bash
   npm run build
   ```
4. **Run apps** for testing:
   ```bash
   npm run dev:playground
   ```

## Creating a PR

1. Create a branch (`git checkout -b feature/your-feature`).
2. Make your changes.
3. Push to your fork and submit a Pull Request.

Please ensure your code is formatted and passes typescript checks.
